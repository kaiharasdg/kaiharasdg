# Kaiharasdg Website

Professional responsive jewelry website for **Kaiharasdg**.

## Included
- Elegant jewelry homepage
- Rings, necklaces, bracelets, and earrings
- Product filters
- Sample prices
- Interactive bag counter
- Brand story and About section
- Newsletter form
- Responsive mobile navigation
- GitHub Pages ready

## Files
- `index.html`
- `styles.css`
- `script.js`

## Publish with GitHub Pages
Upload the files to the root of the `kaiharasdg` repository.
Then open **Settings → Pages → Deploy from a branch → main / root → Save**.

Product names and prices are sample content. Product photography is loaded remotely from Unsplash and can be replaced with your own images.
